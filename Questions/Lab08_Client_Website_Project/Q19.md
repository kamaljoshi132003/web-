## Question 19: Which coding standards help keep the project readable and maintainable?
**Answer:** Follow this checklist:
- Consistent indentation (2 spaces), lowercase tag/attribute names, double quotes.
- Use meaningful class and ID names such as `.hero-slide` and `#booking-form`, with a consistent naming pattern such as BEM (`card__title`).
- Organize CSS with section comments such as `/* ===== Header ===== */` and define shared variables in `:root`.
- Use `const` and `let` in JavaScript, keep functions focused, and add comments where they clarify non-obvious behavior.
- Avoid inline styles and duplicated code.
- Validate HTML at https://validator.w3.org and CSS at https://jigsaw.w3.org/css-validator.
Example:
```javascript
/* Show the slide at index n and hide the current one */
function show(slideIndex) {
  console.log("Showing slide:", slideIndex);
}
```
