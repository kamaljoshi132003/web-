## Question 10: How do you optimize image assets and minify CSS and JavaScript files?
**Answer:**
```bash
# Compress and resize images on Ubuntu
sudo apt install -y imagemagick optipng jpegoptim webp
mogrify -resize 1600x -quality 80 images/*.jpg
jpegoptim --max=80 images/*.jpg
cwebp -q 80 images/hero1.jpg -o images/hero1.webp      # WebP format

# Minify CSS and JavaScript with Node.js
npx csso-cli css/style.css -o css/style.min.css
npx terser js/main.js -c -m -o js/main.min.js
```
Link `style.min.css` and `main.min.js` from the HTML. Also consider `<img loading="lazy">`, `<script defer>`, and limiting the number of font files. Compare file sizes before and after with `ls -lh`.
