## Setup Question: How should you organize the client website project files?
**Answer:** The chosen client is *Crumb & Co.*, a local artisan bakery in Roorkee. You may choose a different client, such as a cafe or fitness studio, and update the project name and content. Use this project structure:
```
crumb-co/
  index.html  booking.html  contact.html
  css/style.css   js/main.js
  images/ (hero1.jpg, hero2.jpg, hero3.jpg, ...)
```
