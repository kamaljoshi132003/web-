## Question 11: How do you test the website across Chrome, Firefox, Edge, and Safari?
**Answer:** Use this checklist while testing each browser; record actual results rather than assuming compatibility.
| Check | Chrome | Firefox | Edge | Safari |
|-------|:-----:|:-------:|:----:|:------:|
| Layout (Grid/Flex) | Not tested | Not tested | Not tested | Not tested |
| Carousel transitions | Not tested | Not tested | Not tested | Not tested |
| Form validation / date input | Not tested | Not tested | Not tested | Not tested |
| Fonts/images load | Not tested | Not tested | Not tested | Not tested |
Open the site in each browser, capture screenshots, and record any problems. Safari is available on macOS and iOS; if those devices are unavailable, use a browser testing service. Check CSS feature support at https://caniuse.com.
