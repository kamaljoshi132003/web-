## Question 20: How do you audit the website's code, accessibility, and performance with Lighthouse?
**Answer:**
1. Open the site in Chrome, press `F12`, and select the **Lighthouse** tab.
2. Select Performance, Accessibility, Best Practices, and SEO. Choose the mobile mode and select **Analyze page load**.
3. Record the scores and resolve issues such as missing alternative text, low contrast, oversized images, or missing descriptions. Run the audit again.
4. Also check accessibility with the WAVE extension at https://wave.webaim.org or axe DevTools. Navigate the entire site with the `Tab` key.
5. Include screenshots of the before-and-after reports in your submission.

Run Lighthouse from the command line with Node.js: `npx lighthouse http://localhost:8000 --view`.
