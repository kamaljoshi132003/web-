## Question 17: How do you run and test the website locally?
**Answer:**
```bash
cd crumb-co
python3 -m http.server 8000          # Then open http://localhost:8000 in a browser.
# Alternatively:
npx serve .                          # Or use the VS Code Live Server extension.
```
To run the site with Apache, copy the folder to `/var/www/html/crumb-co/` and open `http://localhost/crumb-co/`. Test all links, images, and forms.
