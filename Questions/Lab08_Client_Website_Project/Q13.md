## Question 13: What should a design rationale document explain about the website?
**Answer:**
1. **Overview:** client, project goal, and target audience.
2. **Color choices:** explain the warm cream background, trustworthy brown, and orange call-to-action accent. Include measured contrast ratios.
3. **Typography:** explain the Georgia headings, readable body font, and modular scale of approximately 1.25.
4. **Layout:** describe the mobile-first single-column layout and three-column desktop grid, including the use of whitespace.
5. **Audience alignment:** explain touch-friendly buttons, click-to-call phone links, and a straightforward booking flow for local mobile users.
6. **Accessibility:** describe alternative text, ARIA landmarks, keyboard focus, and a 4.5:1 contrast ratio.
7. **Performance and SEO:** describe optimized images, metadata, and semantic HTML.
8. **Conclusion:** summarize how the design meets the project goals.
