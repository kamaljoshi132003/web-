## Question 8: How do you embed a responsive Google Map on the contact page?
**Answer:** In Google Maps, search for the location, select **Share**, then choose **Embed a map** and copy the iframe URL.
```html
<div class="map">
  <iframe src="PASTE_GOOGLE_MAPS_EMBED_URL_HERE"
          title="Crumb & Co. location on Google Maps" loading="lazy" allowfullscreen
          referrerpolicy="no-referrer-when-downgrade"></iframe>
</div>
```
```css
.map{position:relative;width:100%;padding-bottom:56.25%;height:0;overflow:hidden}   /* 16:9 */
.map iframe{position:absolute;inset:0;width:100%;height:100%;border:0}
```
