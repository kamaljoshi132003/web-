## Question 5: How do ARIA landmarks, alternative text, keyboard focus, and color contrast support accessibility?
**Answer:**
```html
<header role="banner"> ... </header>
<nav aria-label="Main navigation"> ... </nav>
<main id="main"> ... </main>
<footer role="contentinfo"> ... </footer>

<img src="images/sourdough.jpg" alt="Golden sourdough loaf on a wooden board">
<img src="images/divider.png" alt="" role="presentation">      <!-- Decorative image -->

<button aria-label="Next slide">&rsaquo;</button>
<label for="phone">Phone</label><input id="phone" type="tel">
```
```css
a:focus, button:focus, input:focus { outline: 3px solid #e07a1f; outline-offset: 2px; }  /* keyboard focus */
.skip { position: absolute; left: -999px; } .skip:focus { left: 8px; top: 8px; background:#fff; padding:6px; }
```
The minimum contrast ratio for normal text is **4.5:1**. Check colors with the WebAIM Contrast Checker. For example, `#3b2f2f` on `#fffaf3` provides strong contrast, while white text on `#e07a1f` may not. Use a darker orange such as `#b85c0d` when needed.
