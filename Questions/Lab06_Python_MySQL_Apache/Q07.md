## Question 7: How do you read form data in a CGI script and insert it into MySQL?
**Answer:**
`/var/www/html/form.html`
```html
<form action="/cgi-bin/add_user.py" method="post">
    Name: <input name="name" required><br>
    Email: <input name="email" type="email" required><br>
    Age: <input name="age" type="number" min="1" max="120" required><br>
  <button>Add</button>
</form>
```
`/usr/lib/cgi-bin/add_user.py`
```python
#!/var/www/venv/bin/python
import os, sys, pymysql
from urllib.parse import parse_qs
from dbconfig import DB

length = int(os.environ.get("CONTENT_LENGTH") or 0)
form = parse_qs(sys.stdin.read(length))
name = form.get("name", [""])[0].strip()
email = form.get("email", [""])[0].strip()
age_text = form.get("age", [""])[0]
print("Content-Type: text/html; charset=utf-8\n")

if not name or not email or not age_text.isdigit() or not 1 <= int(age_text) <= 120:
    print("<h3>Enter a valid name, email address, and age from 1 to 120.</h3>")
else:
    try:
        with pymysql.connect(**DB) as conn:
            with conn.cursor() as cur:
                cur.execute(
                    "INSERT INTO users (name, email, age) VALUES (%s, %s, %s)",
                    (name, email, int(age_text)),
                )
            conn.commit()
        print("<h3>User added successfully</h3><a href='/cgi-bin/list.py'>View users</a>")
    except pymysql.MySQLError:
        print("<h3>Could not add the user.</h3>")
```
