## Question 21: How do you generate a summary report with the user count and age statistics?
**Answer:**
```python
import pymysql
from dbconfig import DB
conn = pymysql.connect(**DB); cur = conn.cursor()
cur.execute("SELECT COUNT(*), AVG(age), MIN(age), MAX(age) FROM users")
cnt, avg, mn, mx = cur.fetchone()
average = f"{avg:.1f}" if avg is not None else "N/A"
print(f"Total users: {cnt}\nAverage age: {average}\nYoungest: {mn}\nOldest: {mx}")
cur.execute("SELECT age, COUNT(*) FROM users GROUP BY age ORDER BY age")
for age, c in cur.fetchall():
    print(f"Age {age}: {c} user(s)")
conn.close()
```
