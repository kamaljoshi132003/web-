## Question 15: How do you define a SQLAlchemy model and use it to insert and query user records?
**Answer:**
```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

engine = create_engine("mysql+pymysql://pyuser:pypass123@localhost/python_web_db")
Base = declarative_base()

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    name = Column(String(100))
    email = Column(String(100))
    age = Column(Integer)

Session = sessionmaker(bind=engine)
s = Session()
s.add(User(name="Tina", email="tina@example.com", age=22))
s.commit()
for u in s.query(User).filter(User.age > 20).all():
    print(u.id, u.name, u.email)
s.close()
```
