## Question 12: How do you reuse database connections with a MySQL connection pool?
**Answer:**
```python
from mysql.connector import pooling
from dbconfig import DB

pool = pooling.MySQLConnectionPool(pool_name="webpool", pool_size=5, **DB)

def get_users():
    conn = pool.get_connection()          # Get a connection from the pool
    try:
        cur = conn.cursor()
        cur.execute("SELECT id, name FROM users")
        return cur.fetchall()
    finally:
        conn.close()                      # Return the connection to the pool

print(get_users())
```
Reusing pooled connections can reduce connection overhead and resource use under concurrent workloads. Because CGI starts a new process for each request, connection pooling is most useful with WSGI or another long-running application.
