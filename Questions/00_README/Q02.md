## Question 2: How should you run the examples and prepare your lab submission?
**Answer:**
- **Labs 1, 2, and 3:** Save each example as an `.html` file and open it in a browser. If an example contains only body content, place it inside this HTML template:
  ```html
  <!DOCTYPE html>
  <html lang="en"><head><meta charset="UTF-8"><title>Lab</title></head>
  <body>
    ...insert the example here...
  </body></html>
  ```
- **Labs 4 and 7:** Use XAMPP on Windows, or install the required packages on Ubuntu with `sudo apt install apache2 php libapache2-mod-php php-mysql mariadb-server`. Place the files in `htdocs` or `/var/www/html`. Open the project at `http://localhost/...`.
- **Labs 5 and 6:** Use Python 3 with Apache CGI or mod_wsgi. Install the Python packages with `pip install pymysql mysql-connector-python sqlalchemy`.
- The credentials shown in examples, such as `root` and `lab123`, are for practice only. Do not use them in production projects.
- Include screenshots of your browser and terminal output in your practical submission.
