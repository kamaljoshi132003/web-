## Question 10: How do you create nested ordered lists using Roman numerals and lowercase letters?
**Answer:**
```html
<ol type="I">
  <li>Frontend
    <ol type="a"><li>HTML</li><li>CSS</li><li>JavaScript</li></ol>
  </li>
  <li>Backend
    <ol type="a"><li>PHP</li><li>Python</li></ol>
  </li>
</ol>
```
