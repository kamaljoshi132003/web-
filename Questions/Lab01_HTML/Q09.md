## Question 9: How do you create a nested list to represent a university course structure?
**Answer:**
```html
<ul>
  <li>MCA
    <ul>
      <li>Semester 1
        <ul><li>Programming in C</li><li>Data Structures</li></ul>
      </li>
      <li>Semester 2
        <ul><li>Web Technology</li><li>DBMS</li></ul>
      </li>
    </ul>
  </li>
  <li>BCA
    <ul><li>Semester 1</li><li>Semester 2</li></ul>
  </li>
</ul>
```
