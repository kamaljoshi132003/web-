## Question 19: How do you display the key and code during `keydown` and `keyup` events?
**Answer:**
```html
<p>Press any key:</p>
<div id="info"></div>
<script>
  const info = document.getElementById("info");
  document.addEventListener("keydown", e => {
    info.textContent = `keydown -> key: ${e.key}, code: ${e.code}`;
  });
  document.addEventListener("keyup", e => {
    info.textContent += `\nkeyup -> key: ${e.key}`;
  });
</script>
```
