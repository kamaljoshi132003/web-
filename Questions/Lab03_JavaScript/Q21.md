## Question 21: How do callbacks and `setTimeout` demonstrate asynchronous JavaScript execution?
**Answer:**
```html
<script>
  function greet(name, callback) {
    console.log("Hello " + name);
    callback();
  }
  greet("Amit", () => console.log("Callback executed"));

  console.log("Start");
  setTimeout(() => console.log("Runs after 2 seconds"), 2000);
  console.log("End");
  // Output order: Start, End, then Runs after 2 seconds
</script>
```
`setTimeout` is asynchronous, so the remaining code continues running and its callback executes later.
