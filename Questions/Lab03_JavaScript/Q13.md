## Question 13: How do you use a closure to create a counter with a private value?
**Answer:**
```html
<script>
  function createCounter() {
    let count = 0;                      // private variable
    return {
      increment: () => ++count,
      decrement: () => --count,
      value: () => count
    };
  }
  const c = createCounter();
  c.increment(); c.increment(); c.decrement();
  console.log(c.value());               // 1
  console.log(c.count);                 // undefined; the private value is not exposed
</script>
```
