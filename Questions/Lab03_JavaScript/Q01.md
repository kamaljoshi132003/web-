## Question 1: How do you read two numbers and display their sum, difference, product, and quotient?
**Answer:**
```html
<script>
  const a = Number.parseFloat(prompt("Enter the first number:") ?? "");
  const b = Number.parseFloat(prompt("Enter the second number:") ?? "");
  if (!Number.isFinite(a) || !Number.isFinite(b)) {
    alert("Enter valid numbers.");
  } else {
    const quotient = b === 0 ? "undefined (division by zero)" : (a / b).toFixed(2);
    const res = `Sum=${a + b}, Difference=${a - b}, Product=${a * b}, Quotient=${quotient}`;
    console.log(res);
    alert(res);
  }
</script>
```
