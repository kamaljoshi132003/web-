## Question 9: How do you delete a student record using an ID passed as a URL parameter with GET?
**Answer:**
Use `delete.php?id=3` to pass the record ID.
```php
<?php
require 'db.php';
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);
if (!$id) { die("Invalid ID"); }
$stmt = $pdo->prepare("DELETE FROM students WHERE id = ?");
$stmt->execute([$id]);
echo $stmt->rowCount() ? "Deleted." : "No such record.";
```
In real projects, use POST with a CSRF token for delete actions instead of GET. GET is used here only to keep the demonstration simple.
