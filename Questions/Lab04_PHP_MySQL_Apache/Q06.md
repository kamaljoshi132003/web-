## Question 6: How do you insert a student record using a prepared statement?
**Answer:**
`insert.php`
```php
<?php
require 'db.php';
$stmt = $pdo->prepare("INSERT INTO students (name, email, enrollment_date) VALUES (:name, :email, :date)");
$stmt->execute([':name' => 'Amit Kumar', ':email' => 'amit@example.com', ':date' => date('Y-m-d')]);
echo "Inserted ID: " . $pdo->lastInsertId();
```
Prepared statements keep SQL code separate from data, helping prevent SQL injection.
