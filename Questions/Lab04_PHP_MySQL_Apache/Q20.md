## Question 20: How do you check that the `mysqli`, `pdo_mysql`, `mbstring`, and `curl` PHP extensions are enabled?
**Answer:**
```bash
php -m | grep -E "mysqli|pdo_mysql|mbstring|curl"
sudo phpenmod mysqli pdo_mysql mbstring curl      # enable
sudo systemctl restart apache2
```
In the XAMPP `php.ini`, enable `extension=mysqli`, `extension=pdo_mysql`, `extension=mbstring`, and `extension=curl` by removing the leading semicolon (`;`). Verify the extensions with this script:
```php
<?php
foreach (['mysqli', 'pdo_mysql', 'mbstring', 'curl'] as $e)
    echo $e . ": " . (extension_loaded($e) ? "ENABLED" : "missing") . "<br>";
```
