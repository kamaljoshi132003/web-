## Question 13: How do you upload a file after validating its size, extension, and content type?
**Answer:**
`upload.php`
```php
<?php
$msg = "";
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_FILES['img'])) {
    $f = $_FILES['img'];
    $ext = strtolower(pathinfo($f['name'], PATHINFO_EXTENSION));
    $allowed = ['jpg' => ['image/jpeg'], 'jpeg' => ['image/jpeg'], 'png' => ['image/png'], 'gif' => ['image/gif']];
    if ($f['error'] !== UPLOAD_ERR_OK)          $msg = "Upload error.";
    elseif (!isset($allowed[$ext]))             $msg = "Only JPG, PNG, and GIF files are allowed.";
    elseif ($f['size'] > 2 * 1024 * 1024)       $msg = "File too large (maximum 2 MB).";
    else {
        $mime = (new finfo(FILEINFO_MIME_TYPE))->file($f['tmp_name']);
        if (!in_array($mime, $allowed[$ext], true)) {
            $msg = "The file content does not match its extension.";
        } else {
            if (!is_dir("uploads")) mkdir("uploads", 0755, true);
            $new = bin2hex(random_bytes(16)) . "." . $ext;
            $msg = move_uploaded_file($f['tmp_name'], "uploads/" . $new)
                ? "Uploaded as $new"
                : "Could not save the uploaded file.";
        }
    }
}
echo $msg;
?>
<form method="post" enctype="multipart/form-data">
  <input type="file" name="img"><button>Upload</button>
</form>
```
On Ubuntu, grant the Apache user permission to write to the `uploads/` folder: `sudo chown www-data:www-data uploads`.
