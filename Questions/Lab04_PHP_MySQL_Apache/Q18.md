## Question 18: How do you inspect Apache access and error logs and generate sample requests?
**Answer:**
```bash
sudo tail -f /var/log/apache2/access.log     # XAMPP: C:\xampp\apache\logs\access.log
sudo tail -f /var/log/apache2/error.log
# Send requests from another terminal:
for i in {1..10}; do curl -s -o /dev/null http://localhost/; done
curl -s -o /dev/null http://localhost/nopage.php       # Generate a 404 response
ab -n 100 -c 10 http://localhost/                      # Run a performance test (install apache2-utils first)
```
The access log records each request's IP address, time, URL, and status code (such as 200 or 404). The error log contains PHP errors and missing-file messages.
