## Question 3: How do you connect to MySQL and create a database named `college_db`?
**Answer:**
```bash
sudo mysql                       # Alternatively: mysql -u root -p
```
```sql
CREATE DATABASE college_db;
SHOW DATABASES;
USE college_db;
```
(In phpMyAdmin, select **New**, enter `college_db` as the database name, and select **Create**.)
