## Question 14: How do you create a restricted MySQL user with only SELECT, INSERT, and UPDATE privileges?
**Answer:**
```sql
CREATE USER 'webapp'@'localhost' IDENTIFIED BY 'StrongPass#123';
GRANT SELECT, INSERT, UPDATE ON college_db.* TO 'webapp'@'localhost';
FLUSH PRIVILEGES;
SHOW GRANTS FOR 'webapp'@'localhost';
```
To verify the permissions, connect with `mysql -u webapp -p college_db` and run `DELETE FROM students WHERE id = -1;`. The command should be denied without affecting any records. You can now use `webapp` instead of `root` in `db.php`.
