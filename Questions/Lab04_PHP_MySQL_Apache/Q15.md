## Question 15: How do you use PHP sessions to log in, protect a page, and log out?
**Answer:**
`s_login.php`
```php
<?php
session_start();
$_SESSION['user'] = 'amit';
echo "Logged in. <a href='s_page.php'>Go to page</a>";
```
`s_page.php`
```php
<?php
session_start();
echo isset($_SESSION['user']) ? "Welcome, " . htmlspecialchars($_SESSION['user']) . " <a href='s_logout.php'>Logout</a>" : "Please login first.";
```
`s_logout.php`
```php
<?php
session_start(); session_unset(); session_destroy();
echo "Logged out.";
```
