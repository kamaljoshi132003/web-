## Question 1: How do you configure Apache and verify that its default page loads at `http://localhost`?
**Answer:**
```bash
sudo systemctl status apache2          # active (running)
curl -I http://localhost               # HTTP/1.1 200 OK
```
Open `http://localhost` in a browser. The "Apache2 Default Page" should appear. To create your own test page, run:
```bash
echo "<h1>Apache works</h1>" | sudo tee /var/www/html/index.html
```
If both `index.php` and `index.html` exist, Apache's `DirectoryIndex` setting determines which file is served first. On Ubuntu, `index.html` usually takes precedence.
