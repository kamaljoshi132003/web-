## Question 12: How do you authenticate a user against records stored in MySQL?
**Answer:**
```sql
USE college_db;
CREATE TABLE users (id INT AUTO_INCREMENT PRIMARY KEY, username VARCHAR(50) UNIQUE, password VARCHAR(255));
```
`login.php`
```php
<?php
require 'db.php';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $stmt = $pdo->prepare("SELECT * FROM users WHERE username = ?");
    $stmt->execute([$_POST['username']]);
    $user = $stmt->fetch();
    echo ($user && password_verify($_POST['password'], $user['password'])) ? "Login successful" : "Invalid credentials";
}
?>
<form method="post">
  <input name="username" placeholder="Username" required><br>
  <input type="password" name="password" placeholder="Password" required><br>
  <button>Login</button>
</form>
```
(Insert users with passwords generated by `password_hash()`; see Q21.)
