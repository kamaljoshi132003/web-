## Question 21: How do you hash a password with `password_hash()` and verify it with `password_verify()`?
**Answer:**
`register.php`
```php
<?php
require 'db.php';
$hash = password_hash("MySecret123", PASSWORD_DEFAULT);
$stmt = $pdo->prepare("INSERT INTO users (username, password) VALUES (?, ?)");
$stmt->execute(['amit', $hash]);
echo "User saved. Hash: " . $hash;
```
`check.php`
```php
<?php
require 'db.php';
$stmt = $pdo->prepare("SELECT password FROM users WHERE username = ?");
$stmt->execute(['amit']);
$hash = $stmt->fetchColumn();
echo password_verify("MySecret123", $hash) ? "Password correct" : "Wrong password";
```
Never store passwords as plain text. `password_hash()` creates a hash using a salt, and `password_verify()` checks a password against that hash.
