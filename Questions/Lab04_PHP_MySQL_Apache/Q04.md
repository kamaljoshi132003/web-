## Question 4: How do you create a PDO connection and display a successful connection status?
**Answer:**
`connect.php`
```php
<?php
require 'db.php';
echo "Connected successfully to " . $pdo->query("SELECT DATABASE()")->fetchColumn();
```
Using PDO, exceptions, and `charset=utf8mb4` is a reliable approach. Store credentials in a configuration file or environment variable instead of hard-coding them in application code.
