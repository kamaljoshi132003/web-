## Question 2: How do you enable PHP error display in `php.ini` and verify the setting with `phpinfo()`?
**Answer:**
```bash
php --ini                                       # Display the php.ini path
sudo nano /etc/php/*/apache2/php.ini            # XAMPP: C:\xampp\php\php.ini
```
Set `display_errors = On` and `error_reporting = E_ALL`, then restart Apache with `sudo systemctl restart apache2`.
`info.php`
```php
<?php phpinfo(); ?>
```
At `http://localhost/lab4/info.php`, search for "display_errors" and confirm that its value is `On`. Delete `info.php` after testing because it exposes server information.
