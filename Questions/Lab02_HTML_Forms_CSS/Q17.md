## Question 17: How do you submit hidden form values, and why should they not contain secrets?
**Answer:**
```html
<form action="process.php" method="post">
  <input type="hidden" name="session_id" value="abc123xyz">
  <input type="hidden" name="user_id" value="45">
  <input type="text" name="comment" placeholder="Comment">
  <button>Send</button>
</form>
```
Hidden fields are not displayed on the page, but users can inspect and modify them in the browser. Do not store sensitive information in hidden fields. Keep session data on the server.
