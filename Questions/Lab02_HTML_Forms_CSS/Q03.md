## Question 3: How can legacy `frameset` and `frame` elements divide a page into sections?
**Answer:** The `frameset` element is obsolete in HTML5 and is included for historical practice only.
`index.html` (a frameset document does not contain a `<body>` element)
```html
<html>
<frameset rows="20%,80%">
  <frame src="header.html" name="header">
  <frameset cols="25%,75%">
    <frame src="nav.html" name="nav">
    <frame src="content.html" name="content">
  </frameset>
</frameset>
</html>
```
`header.html`: `<h1>My Site</h1>`
`nav.html`: `<a href="content.html" target="content">Home</a><br><a href="about.html" target="content">About</a>`
`content.html`: `<h2>Welcome</h2><p>Main content.</p>`
