## Question 21: How do you associate form labels with their inputs to improve accessibility?
**Answer:**
```html
<form>
  <label for="uname">Username:</label>
  <input type="text" id="uname" name="uname"><br><br>
  <label for="mail">Email:</label>
  <input type="email" id="mail" name="mail"><br><br>
  <label for="msg">Message:</label>
  <textarea id="msg" name="msg"></textarea>
</form>
```
The `for` value must match the input's `id`. This lets users focus the input by selecting its label and helps screen readers identify the control.
