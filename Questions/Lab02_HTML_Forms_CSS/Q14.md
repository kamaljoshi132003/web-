## Question 14: How do you update labels live when a range slider or number input changes?
**Answer:**
```html
<label>Volume: <input type="range" id="rng" min="0" max="100" value="30"> <span id="rv">30</span> %</label><br><br>
<label>Weight: <input type="number" id="num" value="50"> kg</label> <b id="nv">50 kg</b>
<script>
  const range = document.getElementById("rng");
  const rangeValue = document.getElementById("rv");
  const number = document.getElementById("num");
  const numberValue = document.getElementById("nv");
  range.addEventListener("input", () => { rangeValue.textContent = range.value; });
  number.addEventListener("input", () => { numberValue.textContent = number.value + " kg"; });
</script>
```
