## Question 11: How do inline, internal, and external CSS rules interact through specificity and source order?
**Answer:**
`contact.html`
```html
<link rel="stylesheet" href="ext.css">
<style>
  /* internal */
  input { border: 2px solid green; }
  #email { border: 2px solid blue; }
</style>
<form>
  <input type="text" placeholder="Name"><br>
  <input type="email" id="email" placeholder="Email"><br>
  <input type="text" placeholder="Phone" style="border: 2px solid red;">
</form>
```
`ext.css`: `input { border: 2px solid gray; padding: 8px; margin: 5px; }`
Specificity order: **inline styles > ID selectors > class selectors > element selectors**. When specificity is equal, the rule that appears later wins. Therefore, the internal `input` rule overrides the external `input` rule, the last input is red because of its inline style, the email input is blue because of its ID selector, and the other input is green.
