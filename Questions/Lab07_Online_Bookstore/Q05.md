## Question 5: How do you implement customer registration and login with hashed passwords and secure sessions?
**Answer:**
`register.php`
```php
<?php
require_once __DIR__ . '/db.php';
$msg = "";
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name = trim($_POST['name'] ?? ''); $email = trim($_POST['email'] ?? ''); $pw = $_POST['password'] ?? '';
    if (strlen($name) < 2 || !filter_var($email, FILTER_VALIDATE_EMAIL) || strlen($pw) < 6) {
        $msg = "Invalid input.";
    } else {
        try {
            $pdo->prepare("INSERT INTO users (name, email, password) VALUES (?, ?, ?)")
                ->execute([$name, $email, password_hash($pw, PASSWORD_DEFAULT)]);
            header("Location: login.php"); exit;
        } catch (PDOException $ex) { $msg = "Email already registered."; }
    }
}
?>
<?php include 'header.php'; ?>
<form method="post" id="regForm" style="padding:24px"><h2>Register</h2><p style="color:red"><?= e($msg) ?></p>
  <input name="name" placeholder="Name" required minlength="2"><br><input type="email" name="email" placeholder="Email" required><br>
  <input type="password" name="password" placeholder="Password" required minlength="6"><br><button>Register</button></form>
<script src="validate.js"></script>
<?php include 'footer.php'; ?>
```
`login.php`
```php
<?php
require_once __DIR__ . '/db.php';
$msg = "";
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $st = $pdo->prepare("SELECT * FROM users WHERE email = ?");
    $st->execute([$_POST['email'] ?? '']);
    $u = $st->fetch();
    if ($u && password_verify($_POST['password'] ?? '', $u['password'])) {
        session_regenerate_id(true);          // Prevent session fixation
        $_SESSION['uid'] = $u['id']; $_SESSION['name'] = $u['name']; $_SESSION['role'] = $u['role'];
        header("Location: index.php"); exit;
    }
    $msg = "Invalid email or password.";
}
?>
<?php include 'header.php'; ?>
<form method="post" id="loginForm" style="padding:24px"><h2>Login</h2><p style="color:red"><?= e($msg) ?></p>
  <input type="email" name="email" placeholder="Email" required><br><input type="password" name="password" placeholder="Password" required><br><button>Login</button></form>
<script src="validate.js"></script>
<?php include 'footer.php'; ?>
```
`logout.php`: `<?php session_start(); session_destroy(); header("Location: index.php");`

To create an administrator, register an account and run `UPDATE users SET role='admin' WHERE email='you@example.com';` in the database.
