## Question 14: How do prepared statements, input validation, and output escaping protect a PHP application?
**Answer:** Apply these rules throughout the project:
- Use `prepare()` with `?` or named placeholders for every query. Never insert request values directly into SQL strings.
- Escape HTML output with `e()` (which uses `htmlspecialchars`) to help prevent cross-site scripting.
- Validate input with tools such as `filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT)`, `FILTER_VALIDATE_EMAIL`, and integer casts.
- Hash passwords with `password_hash()` and call `session_regenerate_id(true)` after successful login.

Unsafe and safe query examples:
```php
// Unsafe: this can allow SQL injection
$pdo->query("SELECT * FROM books WHERE id = " . $_GET['id']);
// Safe: use a prepared statement
$st = $pdo->prepare("SELECT * FROM books WHERE id = ?"); $st->execute([(int)$_GET['id']]);
```
