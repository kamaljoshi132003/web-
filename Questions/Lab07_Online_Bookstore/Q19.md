## Question 19: How do you style the bookstore application with Bootstrap or a shared custom stylesheet?
**Answer:** Add this stylesheet link to the `<head>` element in `header.php`:
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
```
Apply classes, for example:
```html
<nav class="navbar navbar-dark bg-dark px-3"> ... </nav>
<div class="container"><div class="row">
  <div class="col-md-3"><div class="card"><img class="card-img-top" src="..."><div class="card-body">
    <h5 class="card-title">Title</h5><a class="btn btn-primary" href="#">View</a></div></div></div>
</div></div>
<table class="table table-striped"> ... </table>
<form> <input class="form-control"> <button class="btn btn-success">Submit</button> </form>
```
Alternatively, use the shared `style.css` consistently throughout the project, as in Question 1. Choose one approach rather than mixing both stylesheets inconsistently.
