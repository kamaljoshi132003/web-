## Question 10: How do you configure Apache to execute Python CGI scripts from a directory using `.htaccess`?
**Answer:** Apache must allow overrides for the directory:
```apache
# /etc/apache2/conf-available/pyweb.conf
<Directory /var/www/html/pyapp>
    AllowOverride All
</Directory>
```
`/var/www/html/pyapp/.htaccess`
```apache
Options +ExecCGI
AddHandler cgi-script .py
DirectoryIndex index.py
```
```bash
sudo a2enconf pyweb && sudo systemctl reload apache2
sudo chmod +x /var/www/html/pyapp/*.py
```
The `/var/www/html/pyapp/index.py` script can then run directly in a browser if it has a valid shebang and `Content-Type` header.
