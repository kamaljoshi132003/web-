## Question 11: How do parameterized queries help prevent SQL injection?
**Answer:**
```python
import pymysql
from dbconfig import DB
conn = pymysql.connect(**DB); cur = conn.cursor()
search = "Amit' OR '1'='1"                       # Example input that resembles an injection attempt
cur.execute("SELECT id, name FROM users WHERE name = %s AND age > %s", (search, 18))
print(cur.fetchall())                            # The input is treated as a literal value
conn.close()
```
The `%s` placeholders tell the database driver to treat the supplied data as values, not as part of the SQL statement.
