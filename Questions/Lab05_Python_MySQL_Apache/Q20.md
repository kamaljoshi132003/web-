## Question 20: How do you use a Python virtual environment when deploying CGI or WSGI applications with Apache?
**Answer:**
```bash
sudo python3 -m venv /var/www/venv
sudo /var/www/venv/bin/pip install pymysql sqlalchemy
```
For CGI, use `#!/var/www/venv/bin/python` as the script's shebang.
For mod_wsgi, configure `/etc/apache2/conf-available/wsgi-lab.conf` as follows:
```apache
WSGIDaemonProcess pyapp python-home=/var/www/venv python-path=/var/www/wsgi
WSGIProcessGroup pyapp
WSGIScriptAlias /hello /var/www/wsgi/hello.py
```
```bash
sudo systemctl reload apache2
```
