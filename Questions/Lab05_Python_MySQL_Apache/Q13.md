## Question 13: How do you log database errors and request timestamps to a file?
**Answer:**
```python
import logging, pymysql
from datetime import datetime
from dbconfig import DB

logging.basicConfig(filename="/tmp/pyweb.log", level=logging.INFO,
                    format="%(asctime)s %(levelname)s %(message)s")
logging.info("Request received at %s", datetime.now())
try:
    conn = pymysql.connect(**{**DB, "password": "wrong"})
except pymysql.MySQLError as e:
    logging.error("DB connection failed: %s", e)
```
```bash
cat /tmp/pyweb.log
```
When running under Apache, choose a log directory that the `www-data` user can write to, such as `/var/log/pyweb/`.
